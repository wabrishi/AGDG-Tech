# AGDG-Tech Website

Static multi-page website for **AGDG-Tech**, a software and website development service provider.

## Pages
- `index.html` – Home
- `services.html` – Services & packages
- `portfolio.html` – Portfolio with category filters
- `about.html` – About us
- `contact.html` – Contact form & FAQ

## Run locally
Open `index.html` in a browser, or run `python -m http.server` and visit http://localhost:8000.

## Deploy
Hosted with GitHub Pages from the `main` branch root.
